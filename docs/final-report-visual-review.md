## 排版与图注

1. 封面展示项目名称、课程和作者信息。
2. 图片按原始比例排版，图注随图展示角色、页面及操作结果。
3. 统计截图的图注写明筛选日期和统计口径。
4. 附录列出源码、运行说明、测试报告、数据库文档和验收截图的项目路径。
