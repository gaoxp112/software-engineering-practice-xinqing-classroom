# 测试报告

## 执行环境

- Windows 11，本机 Python 3.11+，Flask 3.1.3，SQLite，Microsoft Edge。
- 功能测试：`python -m unittest discover -s tests -v`。
- 性能测试：`python tests\\benchmark.py`。

## 功能结果

2026-11-03 执行 24 项测试，24/24 通过，总耗时 13.598 秒。测试覆盖：

- 健康检查、学生/教师/管理员登录、注册、改密、停用账号拒绝登录。
- 加入课堂、重复情绪提交、匿名标记、个人历史。
- 教师创建课堂、课堂归属保护、实时汇总、匿名参与人数、带 BOM 的 CSV。
- 管理员日期与情绪筛选、全局导出、创建用户、课堂名单维护。
- 无效日期、倒置日期、无效参与者编号、CSRF、角色越权和结束课堂等异常路径。
- 本地连续 24 小时、每 2 小时分桶的趋势统计边界。
- REST API 统一响应、登录/RBAC、课堂统计资源归属、OpenAPI 文档和管理员排班。
- AI 独立服务令牌、置信度阈值、匿名结果入库、无效结果拒绝及 CSV 公式注入防护。
- 视频 AI 工作器读取真实 H.264 MP4 并通过 FFmpeg 抽帧，使用本地模拟视觉 API 完成分类，再经 Flask API 写入隔离 SQLite；验证 AI 来源、情绪、置信度和时间字段。

## 外部视觉 API 验证

2026-11-03 使用配置的视觉 API 对两段 AI 生成视频做了独立端到端验证。五条 AI 结果写入临时数据库副本，并在管理员记录页确认来源、情绪与置信度；正式演示数据库仍无 AI 测试记录。密钥没有写入源码、日志、报告或视频。每个抽帧请求可能计费，网络或 API 额度失效会中断演示；工作器不自动重试，避免不确定响应造成重复请求。

## 性能基准

临时 SQLite 数据库插入 10,003 条情绪记录后的本机实测：

| 场景 | 中位数 | P95 |
| --- | ---: | ---: |
| 管理员统计概览 | 35.64 ms | 49.06 ms |
| 情绪记录分页 | 15.13 ms | 22.28 ms |
| 完整 CSV 导出 | 129.44 ms | 133.51 ms |

2026-11-03 在临时 SQLite 数据库插入 10,003 条记录后重跑，三项均低于页面 P95 500 ms 和 CSV 3 秒目标。以上是 Flask 测试客户端与本机 SQLite 的单机基准，不等同于公网并发压测。
