# 屏幕演示视频拍摄流程

成片约 4 分钟。使用 1920×1080 或 1366×768 桌面分辨率，浏览器缩放保持 100%。

## 拍摄前

1. 在项目目录运行 `start.bat`，打开 `http://127.0.0.1:5000`。
2. 按 [README](../README.md) 准备样例课堂和学生、教师、管理员演示账号。
3. 用教师账号进入一堂开放课堂，试开摄像头，确认预览、人脸框和情绪标签出现，再点击「停止识别」。

## 镜头顺序

| 时间 | 画面与操作 | 讲解词 |
| --- | --- | --- |
| 0:00–0:15 | 展示系统登录页与项目名称。 | “心晴课堂为学生提供情绪打卡，为教师和管理员提供课堂反馈与统计。” |
| 0:15–0:55 | 学生登录后进入一堂课，选择「困惑」，填写说明并提交，再打开个人记录。 | “学生可选择六类感受，补充说明并回看自己的情绪变化。” |
| 0:55–1:35 | 教师登录并打开同一课堂的看板，展示最新反馈、情绪分布、趋势和教学建议。 | “教师可以查看最近的反馈，结合情绪变化调整讲解节奏。” |
| 1:35–2:50 | 在教师看板点击「开始识别」，面向镜头。录下实时人脸框、情绪标签和置信度，等到采样计数增加后点击「停止识别」。 | “系统在本机识别摄像头画面，将达标的采样匿名计入课堂。” |
| 2:50–3:40 | 管理员登录，按课程或班级筛选统计，进入情绪数据页，展示 AI 来源与置信度并导出 CSV。 | “管理员可以按条件查看统计和明细，并导出筛选结果。” |
| 3:40–4:00 | 展示项目目录、用户手册和测试报告。 | “项目提供源码、运行说明、用户手册与测试材料。” |
