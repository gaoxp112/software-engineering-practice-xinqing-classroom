# 屏幕演示视频拍摄流程

建议成片约 4 分钟，使用桌面分辨率 1920×1080 或 1366×768，浏览器缩放保持 100%。本项目提供的三段 MP4 是 AI 分析输入素材，不是最终屏幕演示视频；最终需要录下系统操作和结果。

## 拍摄前

1. 在项目目录先运行 `start.bat`，确认浏览器可打开 `http://127.0.0.1:5000`。
2. 确认本地数据库保留样例数据：当前样例快照为 17 个用户、13 个课堂、223 条情绪记录、155 条参与关系；当前有 8 个开放课堂。正式演示库初始为 0 条 AI 记录。
3. 确认已安装项目依赖，FFmpeg 可用，且 `models/` 中包含两份 ONNX 权重。
4. 关闭桌面通知、聊天窗口和含个人信息的浏览器标签；全程使用项目里的虚构样例数据，不拍真实学生。
5. 预先准备 `student`、`teacher`、`admin` 三个演示账号及密码，账号见项目根目录 README。每次运行演示都会写入一批新记录。

## 建议镜头顺序

| 时间 | 画面与操作 | 可选讲解词 |
| --- | --- | --- |
| 0:00–0:15 | 展示系统登录页与项目名称。 | “这是心晴课堂表情符号课堂情绪检查器，面向学生课堂反馈、教师查看和管理员统计。” |
| 0:15–0:55 | 学生登录；展示多个开放课堂；进入一堂课，选择“困惑”，填写简短说明并提交；打开个人历史。 | “学生可以加入不同课堂，多次记录六类感受，也可以匿名提交并回看自己的历史。” |

## 操作注意

- 一键演示默认选择最近开放课堂；项目当前已有开放课堂，不必临时新建。运行后会在随机本地端口启动独立临时服务，并打开管理员记录页。
- 浏览器打开记录页后需要用管理员账号登录。确认记录出现 `AI` 来源和置信度后，再回到命令窗口按 Enter 关闭服务。
- 10 秒视频默认约每 3.3 秒抽一帧，通常产生 3 次本地推理。样例名表示预期表情，页面应展示模型实际输出。
- 画面中的 confidence 是模型输出的分类分数，未经概率校准。
- 若录制中断，临时服务在窗口退出时会关闭；重新拍摄可再次运行。不要展示 API 配置、访问令牌或个人数据。

## 交付前核对

- 视频能从头播放，系统名称和关键操作看得清，旁白不遮住重要提示。
- 至少出现学生提交、教师课堂反馈、管理员统计/导出、AI 结果入库四个环节。
- 结尾能看到 AI 来源与置信度；不要把 AI 输入样例视频误当成最终屏幕演示视频提交。
