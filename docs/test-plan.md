## 权限与安全测试

验证未登录跳转、学生访问教师/管理员页面返回 403、教师不能读取他人课堂、CSRF 缺失返回 400、停用账号不能登录、超长说明拒绝、无效课堂 ID 返回 404。

## 定量指标

- 关键流程集成测试 100% 通过。
- 权限越权用例 100% 通过。
- 1 万条记录下列表页 P95 目标小于 500 ms，CSV 导出目标小于 3 秒。
- 移动端 390×844 和桌面端 1440×900 无横向页面溢出，表格允许局部横向滚动。
