# AI 视频分析演示素材

## 严格需求结论

实验指导书要求的链路是：摄像头视频 → 帧采样 → 人脸检测 → 情绪分类 → 置信度过滤 → 情绪/emoji 映射 → 关联课堂 → 调用后端 API 写入数据库。AI 集成单列 10% 评分，并要求进行“模拟视频帧输入 → 结果落库”的集成测试。

因此，正式验收应当展示能够检测的人脸。指导书没有要求必须采集真实学生身份；为避免真实人脸隐私，本目录使用 AI 生成的虚构成年学生脸。素材不对应任何真实个人，也不应当用于心理诊断、考勤或学生评价。

## 最终案例

- `AI案例1-平静到开心-10秒.mp4`：课堂开始时平静，理解知识点后开心。
- `AI案例2-困惑到焦虑-10秒.mp4`：出现理解障碍，随后需要教师关注。
- `AI案例3-平静困惑开心-10秒.mp4`：10 秒内包含三种状态，适合验证连续抽帧和去重策略。

三个文件均为标准 H.264 MP4、1280×720、24 FPS、10 秒、YUV420P limited range，并将 MP4 索引放在文件开头，可由 Windows 播放器、主流浏览器和 PowerPoint 直接播放。

## 私有视觉测试

2026-11-03 使用 `judge.env.example` 配置的 OpenAI 兼容网关进行测试：

- 使用 `gpt-6.1-sol` 视觉输入；
- 每次请求均设置 `store=false`；
- 只上传 AI 生成的虚构图片，不上传真实人物；
- API 密钥只在当前进程读取，没有写入源码、日志、文档或视频。

抽样结果：

| 目标画面 | 人脸检测 | 模型分类 | 模型置信度 |
| --- | --- | --- | ---: |
| 平静 | 是 | calm | 0.88 |
| 开心 | 是 | happy | 0.97 |
| 困惑 | 是 | confused | 0.91 |
| 焦虑 | 是 | anxious | 0.89 |

这些结果证明素材含有可识别的人脸与清楚的表情线索，但不代表生产级表情模型在真实课堂中的准确率。模型返回的 confidence 是模型自报分数，不是校准概率。实际演示仍应说明光照、姿势、文化差异可能影响模型判断。

## 使用方式

1. 将视频作为 AI 工作器输入，而不是上传到数据库；
2. 每秒抽取 1～2 帧即可，无需分析全部 24 FPS；
3. 只把情绪类别、置信度、时间、课堂 ID 和设备 ID 发送到后端；
4. 低于阈值的结果拒绝入库；
5. 原始视频、人脸截图和人脸特征默认不保存；
6. 在管理员记录页确认新记录的 `source=AI`。

生成脚本为 `scripts/build_realistic_demo_videos.py`。`generated/` 保存四张虚构人脸源图，便于复现实验和抽样测试。

双击项目根目录的 `run_video_demo.bat` 可用本地模型分析视频，并将结果写入最近开始的开放课堂。脚本默认约每 3.3 秒抽一帧，并使用 0.65 的分类分数阈值。

本地模型对案例 3 的三帧输出依次为中性、悲伤、开心，均通过 0.65 阈值。映射后入库的类别依次为平静、疲惫、开心。上文的外部视觉 API 实测记录保留供参考。
